## 1. Алгоритмы
**Алгоритм** - точное и понятное исполнителю предписание описывающее порядок действий для достижения указанной цели

Свойства алгоритма
1. Дискретность
2. Выполнимость
3. Определенность
4. Массовость
5. Вход/Выход

Виды структур:
1. Линейный - без ветвлений
2. Разветвляющийся - В зависимости от условия выполняется определенная последовательность
3. Циклический - последовательность которая выполняется многократно

Каждое исполнение цикла - итерация

Тело цикло указывается один раз но может использоваться многократно

Цикл с параметром ( со счетчиком): for
Цикл с предусловием - while
Цикл с постусловием
