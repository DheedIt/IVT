# Тема 1. Метод математической индукции (ММИ)

**ММИ** – способ доказательства утверждений, зависящих от натурального аргумента

Натуральный аргумент – зависимость, в которой независимая переменная (n) принимает только целые положительные значения из множества натуральных чисел n = {1,2,3,4,…}

Доказательство справедливости утверждения **S****(n****)** для любого натурального **n** проводится в 3 этапа.

1.      База индукции – проверка справедливости утверждения **S****(n****) для n****=n****0** (Любое число, обычно n0 = 1)

2.      Индукционное предположение. На этом этапе предполагается справедливость утверждения **S****(n****)** при некотором натуральном **n** **= k** (Любое число, абстрактно)

3.      Индукционный переход. Доказывается справедливость утверждения S(n) для числа **n****=k****+1**, отталкиваясь от Индукционное предположение.

## Пример

Докажите что число a(n) = n^3 + 3n^2 +5n при любом n натуральном ( n E N ) кратно 3  
Решение ММИ

1.      **n = 1**: a(1) = 1^3 + 3*1^2+5*1 = 9 – **верно**

2.      **n****= k**: a(k) = k^3 + 3k^2+5k – предполагаем что кратно 3

3.      **Индукционный переход** n=k+1: a(k+1) = (k+1)^3+3(k+1)^2+5*(k+1)

= k^3 + 3k^2 + 3k + 1 + 3k^2 + 6k + 3 + 5k + 5

= **k****^3+3k****^2+5k**(a(k) кратно 3 по индукционному предположению)+3k^2 + 9k + 9 = a(k) + 3(k^2 + 3k + 3)

a(k+1) кратно 3

Следовательно число a(n) = n^3 + 3n^2 + 5n кратно 3 при любом натуральном n E N
